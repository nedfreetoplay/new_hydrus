Источник: `hydrus_python/hydrus/external`.

Цель: перенести все публичные модули external-пакета на Rust, сохранить
поведение парсеров и покрыть результат тестами.

- [ ] Определить публичный API `hydrus_external` и структуру модулей.
- [ ] Добавить зависимости (`hydrus_core`, `regex`, `chrono`).
- [ ] Подключить модули в `lib.rs`.
